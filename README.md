🛒 Banco de Dados da Conveniência JB

📌 Sobre o projeto
Projeto de banco de dados relacional desenvolvido em MySQL para gerenciar produtos, estoque, clientes, fornecedores e vendas de uma mercearia.

🎯 Objetivo
Organizar as informações da mercearia por meio de um banco de dados estruturado, facilitando o controle dos registros e a consulta de informações.

🗂️ Estrutura do banco
O projeto possui 7 tabelas:
- Categoria
- Fornecedor
- Produto
- Cliente
- Funcionário
- Venda
- Item_Venda

🔗 Relacionamentos
Foram utilizados relacionamentos entre as tabelas por meio de chaves primárias (PK) e estrangeiras (FK), garantindo a organização e integridade dos dados.

💻 Tecnologias utilizadas
- MySQL
- SQL
- MySQL Workbench

📊 Consultas desenvolvidas
- Cálculo do valor total de cada venda.
- Identificação de produtos com estoque baixo.
- Identificação dos produtos mais vendidos.

👨‍💻 Minha contribuição
Participei da estruturação do banco de dados, organização das tabelas, definição dos relacionamentos e desenvolvimento de consultas SQL.

📚 Aprendizados
O projeto contribuiu para aprofundar meus conhecimentos em banco de dados relacionais, modelagem de dados, comandos SQL e organização de informações.
